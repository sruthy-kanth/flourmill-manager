# മില്ല് മാനേജ്‌മെന്റ് സിസ്റ്റം (Flour Mill Management Web App)

ചെറിയ മാവ് മില്ലുകൾക്കായി പ്രത്യേകം രൂപകൽപ്പന ചെയ്ത, പൂർണ്ണമായും മലയാളത്തിലുള്ള പ്രൊഡക്ഷൻ-റെഡി വെബ് ആപ്ലിക്കേഷൻ.

---

## 🌟 പ്രധാന സവിശേഷതകൾ (Key Features)

- **പൂർണ്ണ മലയാളം ഇന്റർഫേസ്**: എല്ലാ ബട്ടണുകളും മെനുകളും സന്ദേശങ്ങളും ലളിതമായ മലയാളത്തിൽ.
- **തൽക്ഷണ എൻട്രി (Fast 1-Tap Entry)**: ഉടമയ്ക്ക് കുറഞ്ഞ നിമിഷങ്ങൾക്കുള്ളിൽ കസ്റ്റമറുടെ ഓർഡർ രേഖപ്പെടുത്താം.
- **ഓട്ടോമാറ്റിക് തുക കണക്കുകൂട്ടൽ**: അളവ് (Quantity) × നിരക്ക് (Rate) = ആകെ തുക (Total Amount) തത്സമയം കണക്കാക്കുന്നു.
- **7 പ്രാരംഭ സേവനങ്ങൾ (Preloaded Operations)**:
  1. അരി പൊടിക്കാൻ
  2. ഗോതമ്പ് പൊടിക്കാൻ
  3. മുളക് പൊടിക്കാൻ
  4. മഞ്ഞൾ പൊടിക്കാൻ
  5. തേങ്ങ ആട്ടിക്കാൻ
  6. അരി വറുക്കാൻ
  7. അവലോസ് വറുക്കാൻ
- **വരുമാന ഡാഷ്‌ബോർഡ്**:
  - ഇന്നത്തെ വരുമാനം (Today's Income - ₹)
  - ഇന്നത്തെ ഇടപാടുകൾ (Today's Transaction count)
  - ഇന്നത്തെ സേവനങ്ങളുടെ എണ്ണം (Active services)
  - വേഗത്തിലുള്ള 1-ക്ലിക്ക് എൻട്രി ബട്ടണുകൾ
- **ഇടപാടുകളുടെ വിവരങ്ങൾ (History)**:
  - തീയതി, സേവനം, കസ്റ്റമർ ഫോൺ നമ്പർ അനുസരിച്ചുള്ള ഫിൽട്ടറുകൾ.
  - ഇടപാട് എഡിറ്റ് ചെയ്യാനും ഇല്ലാതാക്കാനും സാധിക്കുന്നു.
  - ഇല്ലാതാക്കുമ്പോൾ മലയാളത്തിലുള്ള സ്ഥിരീകരണ സന്ദേശം ("ഈ ഇടപാട് ഇല്ലാതാക്കണോ?").
  - മൊബൈലിൽ കാർഡുകളായും ഡെസ്‌ക്‌ടോപ്പിൽ ടേബിളായും കാണാം.
- **പ്രതിമാസ സ്റ്റേറ്റ്മെന്റ് (Monthly Statements)**:
  - വർഷവും മാസവും തിരഞ്ഞെടുക്കാം.
  - ആ മാസത്തെ ആകെ വരുമാനവും ഇടപാടുകളും.
  - സേവന തിരിച്ചുള്ള അളവും വരുമാനവും ശതമാനവും (Progress Bars).
  - ദിവസേനയുള്ള കണക്കുകൾ (Daily breakdown, e.g. 01 സെപ്റ്റംബർ — ₹850).
- **സേവന മാനേജ്‌മെന്റ് (Operations & Rates)**:
  - പുതിയ സേവനങ്ങൾ ചേർക്കാം, നിരക്കുകൾ മാറ്റാം.
  - പഴയ ഇടപാടുകളിലെ തുക മാറ്റമില്ലാതെ സുരക്ഷിതമായി സൂക്ഷിക്കുന്നു.
  - ആവശ്യമില്ലാത്ത സേവനങ്ങൾ താൽക്കാലികമായി നിർത്തിവെക്കാം (`is_active = false`).
- **ഡാറ്റാബേസ് സുരക്ഷ & ഓഫ്‌ലൈൻ റെഡിനസ്**:
  - Supabase PostgreSQL ഡാറ്റാബേസ് സപ്പോർട്ട്.
  - Supabase കോൺഫിഗർ ചെയ്യാത്തപ്പോഴും ലോക്കൽ സ്റ്റോറേജ് വഴി പൂർണ്ണമായി പ്രവർത്തിക്കും.

## 🚀 ആരംഭിക്കുന്ന വിധം (How to Run Locally)

### 1. ഡിപെൻഡൻസികൾ ഇൻസ്റ്റാൾ ചെയ്യുക
```bash
npm install
```

### 2. ആപ്പ് പ്രവർത്തിപ്പിക്കുക
```bash
npm run dev
```
ബ്രൗസറിൽ `http://localhost:5173` തുറക്കുക.

### 3. പ്രൊഡക്ഷൻ ബിൽഡ്
```bash
npm run build
```

## 🗄️ Supabase ഡാറ്റാബേസ് കോൺഫിഗറേഷൻ (Database Setup)

1. [Supabase](https://supabase.com)-ൽ ഒരു പുതിയ പ്രോജക്റ്റ് തുടങ്ങുക.
2. പ്രോജക്റ്റിലെ **SQL Editor** തുറന്ന് പ്രോജക്റ്റിലെ `supabase_schema.sql` ഫയലിലെ കോഡ് റൺ ചെയ്യുക.
3. **Project Settings > API** യിൽ നിന്ന് `Project URL` ഉം `anon public key` യും എടുത്ത് ആപ്പിലെ **ക്രമീകരണങ്ങൾ (Settings)** പേജിൽ നൽകുക അല്ലെങ്കിൽ `.env` ഫയൽ ഉണ്ടാക്കുക:

```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-public-key
```
